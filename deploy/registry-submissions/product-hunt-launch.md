## First comment (announce in the comments after launch)
```
Hi PH! We built SMB Broker because we kept seeing AI agents fail
to interact with the long tail of small businesses — barbers,
plumbers, accountants — who don't have APIs.

The horizontal layer they were missing:
• 19 tools agents can call (find/schedule/message/lead/...)
• Compliance gate (TCPA/GDPR/CASL/10DLC/recording consent) — non-bypassable
• Channel fallback: direct API → voice AI → SMS → email → web form
• Free tier: 100 ops/month, no credit card

Discoverable on day one through:
• MCP (Claude Desktop / Cursor / Continue / Cline)
• OpenAI function calling
• Anthropic tool_use
• A2A protocol
• llms.txt for LLM crawlers

Pricing aligned with value: $1.00 only on confirmed bookings,
$0.15 if booking fails. Builds the right incentives.

We'd love feedback from agent builders + SMB-focused founders.
What capabilities are agents asking for that we should add next?
```
